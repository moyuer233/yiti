# ===== 易体 / Yiti 界面文案（中文） =====
#
# 格式：key=文本            （# 开头是注释，空行忽略）
#       \n 表示换行（就写反斜杠 + n 两个字符）
#
# 怎么改：**只改等号右边的文字，左边的 key 不要动**——代码是按 key 取字的。
# 改完重新编译（build-wpf.ps1）就会打进 exe。
#
# key 前缀对应界面位置：
#   app.     应用名 / 左侧导航 / 窗口标题
#   font.    字体替换页（源字体、五个目标、系统元素、底部按钮、顶部提示条）
#   adv.     高级页（清缓存、用户级字体、生成、还原、备份管理、输出日志）
#   about.   关于页（作者、界面语言、项目主页）
#   backup.  备份管理窗口（列表、删除、还原、清理暂存）
#   picker.  选择字体窗口
#   dlg.     确认框 / 信息框里的按钮
#   msg.     状态栏文字与结果提示（有些是拼在数字前后的片段）
