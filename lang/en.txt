# About page, mirroring the README
sec.features=Features
about.f1=Replaces the system fonts: Settings, Start menu, taskbar and title bars all follow
about.f2=Weight matching: pick one font, regular/bold/light match 400/700/300 automatically
about.f3=Shell elements: small caption, menu, message box, status bar, icon
about.f4=Automatic backup and rollback; originals can also be taken from the Windows component store
about.f5=Adapts to the OS: fonts missing on older systems are greyed out with a reason
sec.diff=How it differs from noMeiryoUI
about.diff=noMeiryoUI changes the UI font setting and cannot reach the taskbar, preinstalled apps or the Windows 11 title bar; Yiti replaces the font files themselves, so all of those change.
sec.systems=Supported systems
about.sys1=Windows 7: YaHei regular/bold + Segoe UI (no Light, no Segoe UI Variable)
about.sys2=Windows 10 1809+: all five files
about.sys3=Windows 11 22000+: all five files, Mica window background
sec.files=Files replaced
about.file1=msyh.ttc Microsoft YaHei Regular
about.file2=msyhbd.ttc Microsoft YaHei Bold
about.file3=msyhl.ttc Microsoft YaHei Light (Windows 8 and newer)
about.file4=SegUIVar.ttf Segoe UI Variable (Latin, taskbar)
about.file5=segoeui.ttf Segoe UI (classic English UI)
sec.how=How it works
about.how1=Build: read your font, rewrite the internal family names to Microsoft YaHei / Segoe UI, glyph data untouched
about.how2=Replace: back up the originals, fix permissions, queue the new files for a boot-time rename
about.how3=Apply: Windows swaps the files at boot and rebuilds the font cache
sec.risks=Risks
about.r1=A font with incomplete coverage or missing weights can leave boxes or blurry text
about.r2=Office / WPS layout, export and printing can change
about.r3=Feature updates reset the system fonts; apply again afterwards
about.r4=Create a restore point before the first run
