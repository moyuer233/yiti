# ===== Yiti UI strings (English) =====
#
# Format: key=text             (# starts a comment, blank lines are ignored)
#         \n means a line break (backslash + n as two characters)
#
# Only edit the text on the right of '='. Keys are looked up by the code - do not rename them.
# Rebuild with build-wpf.ps1 to embed the text into the exe.
#
# Key prefixes tell you where the string appears:
#   app.     app name / left navigation / window title
#   font.    font replacement page (source font, five targets, shell elements, bottom buttons, banner)
#   adv.     advanced page (cache, per-user fonts, generate, restore, backups, log)
#   about.   about page (author, UI language, project home)
#   backup.  backup manager window (list, delete, restore, clear staging)
#   picker.  font picker window
#   dlg.     buttons inside confirm / info dialogs
#   msg.     status-bar text and result messages (some are fragments around a number)
